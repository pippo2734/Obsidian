【SQL】
　・SQLとは、関係データベース管理システム (RDBMS) において、データの操作や定義を行うための
　　データベース言語（問い合わせ言語）、ドメイン固有言語である。（出典：ウィキペディア）
　・データベース言語の国際標準としての「SQL」は略語ではない
　・現在はISOでSQLの標準規格が定まっているので、データベース側のシステムが変わったとしても構文ルールは同じ
　　※RDBMS…SQLServerやOracleDBに代表されるDBソリューション

　・DBに対する命令は大別すると以下の7種類になります。
　　　データ定義文
　　　　CREATE （データベースオブジェクト（表、インデックス、制約など）の定義）
　　　　DROP （データベースオブジェクトの削除）
　　　　ALTER （データベースオブジェクトの定義変更）

　　　データ操作文
　　　　INSERT INTO （行データもしくは表データの挿入）
　　　　UPDATE ～ SET （表を更新）
　　　　DELETE FROM （表から特定行の削除）
　　　　SELECT ～ FROM ～ WHERE （表データの検索、結果集合の取り出し）
