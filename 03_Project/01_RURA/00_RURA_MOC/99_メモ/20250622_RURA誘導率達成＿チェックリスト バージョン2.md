## 🎯 目的
「その場のフロント品質を握る責任者」として、接客導線の最適化とRURA誘導率向上を同時に実現するための行動基準

---

| No  | チェック項目                               | 説明（目的ベース）                | 自己評価（〇／×） |
| --- | ------------------------------------ | ------------------------ | --------- |
| 1   | カウンター外に立ち、全体の様子を把握していた               | 顧客の入館にいち早く気づき、初動を先取りするため |           |

| 3   | RURA前で顧客が戸惑っていた場合、すぐにサポートに入っていた      | 顧客不安を解消し、離脱や不満を防ぐため      |           |

| 6   | 忙しい時間帯こそ「誘導すべき手続き」を優先してRURAへ送客していた   | RURAの役割最大化と人時効率の確保のため    |           |
| 7   | 手続き後の顧客へも「お礼」や「次回もRURAで」の声かけをしていた    | リピート利用・RURA定着率を上げるため     |           |
| 8   | RURAの機材や資料が使いやすい状態に整備されていた           | 誘導・案内の障害を取り除くため          |           |
