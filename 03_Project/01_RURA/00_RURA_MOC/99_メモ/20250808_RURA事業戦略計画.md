## **Coherent Actions｜短期（〜1年）**

> **目的**：RURAを「使うのが前提」の空気感と制度を作り、成果責任をクラブに紐づける

|分類|行動内容|ポイント|
|---|---|---|
|**制度化**|- 「RURA未使用」＝本社承認制にする- 新規採用時は「RURA稼働状況」チェック必須|使わないほうが面倒な構造にする|
|**可視化**|- クラブ別のRURA利用率・削減時間・利益寄与を毎月共有- 使っていないクラブが異常に見える社内レポートを作成|「利用＝当たり前」の空気づくり|
|**責任明文化**|- RURA導入クラブは「生まれた時間の利益化責任はクラブ所属者にある」ことを通達・規定化|責任の所在を曖昧にしない|
|**成功事例拡散**|- 人手不足クラブの成功事例を動画・スライド化して全社共有|「RURAは成果を出す」が常識化|
|**矛盾可視化**|- 「RURAがあるのに採用増やす」クラブを事例化し、損失シミュレーションを提示|説得ではなく“損”を見せる|



## **Coherent Actions｜中長期（〜3年）**

> **目的**：RURAを顧客接点DX・省人化モデルの戦略基盤として昇格させる

| 分類           | 行動内容                                    | ポイント                 |
| ------------ | --------------------------------------- | -------------------- |
| **再定義**      | - RURAを「顧客接点プラットフォーム」として経営方針に明記         | 人手不足対応の枠を超える         |
| **業績連動**     | - RURA活用が売上・顧客満足度・人時売上にどう直結しているかのKPIを設定 | 経営層に刺さる指標で語る         |
| **強制力強化**    | - 本社ルールに基づき、RURAがオペレーション是正を求める権限を制度化    | RURAの地位確立            |
| **省人化モデル設計** | - 1名運営・小規模高収益クラブ運営のパッケージ化（RURA必須）       | 「RURAなしでは成り立たない」モデルに |
| **第三者評価**    | - 外部コンサルや監査でRURAの成果を客観評価し、事業戦略レベルで提案    | 社内外から承認される形に         |
