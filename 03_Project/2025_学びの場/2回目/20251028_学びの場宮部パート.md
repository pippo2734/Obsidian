# タイトル：出力形式を制する者が、AIを制す
## 副題：目的に応じた最適な形式を選び、ほしい情報を正確に引き出す

---

## 0. 導入

**私（話し手）：**  
今日は、生成AIから“狙った答え”を正確に引き出すための方法を紹介します。  
テーマはこちらです。

> **「出力形式を指定して、ほしい情報を得よう！！」**

AIに「いい感じでまとめて」とお願いしていませんか？  
たとえば人にこう頼むと──

> 「レポートをいい感じにまとめておいて」

って言われたら、正直困りますよね。  
「いい感じ」とは？ 書式は？ 提出方法は？ 期日は？  
…人によって解釈がバラバラです。

---

## 1. 曖昧な指示では、曖昧な結果しか得られない

**私：**  
生成AIも同じです。  
“曖昧な指示”を出せば、“曖昧な回答”しか返ってきません。

でも逆に、「どういう形で答えてほしいか」を指定すれば、  
回答の精度と再現性は一気に上がります。

---

## 2. 今日の目的

> **目的に応じた最適な出力形式を選び、AIからほしい情報を正確に引き出すこと。**

今日は実際に、代表的な **5つの出力形式** を紹介します。

## 3. 本日紹介する厳選5形式

1. **ステップバイステップ形式（📝）**  
2. **表形式（📊）**  
3. **箇条書き形式（📌）**  
4. **フローチャート（🔄）**  
5. **パレート分析表（📈）**

---

## 4. それぞれの特徴と使いどころ

### ① ステップバイステップ形式（📝）

**特徴：**  
手順を順序立てて明示できる。  
**使いどころ：**  
- 問題解決のプロセス設計  
- 新人教育・手順共有  
**例：**  
> 「○○を実行する手順を、1→2→3の順でステップバイステップで説明してください。」

---

### ② 表形式（📊）

**特徴：**  
原因・対策・影響などを整理して俯瞰できる。  
**使いどころ：**  
- 要因分析・対策立案  
- KPI整理  
**例：**  
> 「A案・B案・C案を、メリット・デメリット・コストで比較する表を作成してください。」

---

### ③ 箇条書き形式（📌）

**特徴：**  
アイデア出しや要因洗い出しに向く。  
**使いどころ：**  
- ブレスト・初期整理  
- 初期調査段階  
**例：**  
> 「○○の課題を思いつく限り箇条書きで5つ挙げてください。」

---

### ④ フローチャート（Mermaid形式／🔄）

**特徴：**  
問題の流れや分岐を可視化できる。  
**使いどころ：**  
- 例外処理分析  
- 業務フロー確認  
**例：**  
> 「○○の対応フローをMermaid形式で出力してください。」

---

### ⑤ パレート分析表（📈）

**特徴：**  
多数の問題を“影響度順”に並べて可視化できる。  
**使いどころ：**  
- 対策の優先順位づけ  
- リソース配分の検討  
**例：**  
> 「要因を影響度の高い順に並べて、パレート表にしてください。」

---

## 5. その他の便利な出力形式

| 分類 | 形式 | 主な用途 |
|------|------|----------|
| 高評価グループ | Q&A形式 | 原因追及・FAQ作成 |
|  | チェックリスト形式 | 再発防止・運用定着 |
|  | 因果関係リスト（原因→結果） | 根本原因分析 |
| 専門用途 | JSON／CSV形式 | データ分析・自動化連携 |
| 実用グループ | ロールプレイ形式 | 接客トラブル対応訓練 |
|  | Before／After比較表 | 改善報告 |
|  | リスクと対策テーブル | 新制度導入時 |
|  | Yes／No分岐リスト | 現場判断ルール |
|  | 要約＋詳細（TL;DR形式） | レポート作成 |
|  | 優先順位付きタスク表 | アクションプラン策定 |
|  | ロジックツリー形式 | MECE整理 |

---

## 6. どの形式を使えばいい？（選び方ガイド）

| 目的 | 向いている形式 |
|------|----------------|
| 全体像を俯瞰したい | 表形式 |
| 手順を明確にしたい | ステップバイステップ形式 |
| 分岐や例外が多い | フローチャート |
| アイデアを洗い出したい | 箇条書き形式 |
| 優先順位をつけたい | パレート分析表 |

**組み合わせ活用の例：**  
- 「構造化 → 比較 → 流れ」を整理：箇条書き → 表形式 → フローチャート  
- 「重要度 → 行動計画」：パレート分析 → タスク表  
- 「手順 → 点検項目化」：ステップバイステップ → チェックリスト

## 7. まとめ

**私：**  
- 抽象的な指示では、結果も抽象的になる。  
- 具体的に「どの形式で答えてほしいか」を指定するだけで、AIの精度は劇的に上がる。  
- 出力形式を制する者が、AIを制す。
