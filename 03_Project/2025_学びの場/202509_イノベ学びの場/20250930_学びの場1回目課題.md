# 顧客体験と顧客満足度
| 項目        | 顧客満足度（CS）                  | 顧客体験（CX）                         |
| --------- | -------------------------- | -------------------------------- |
| フォーカスする時点 | 主に **購入後・利用後** の満足度        | **購入前 → 購入 → 利用 → 継続** にわたる一連の体験 |
| 視点        | 結果（期待 vs 実際）に対する評価         | 顧客が通る「接点（タッチポイント）」すべて            |
| 能動／受動     | どちらかというと受動的（企業提供の価値に対する反応） | 顧客の行動・感情が主体となる                   |
| 関係性       | リピートやクレーム防止のための指標          | “ファン化” やブランド愛着を目指す手段             |
| 範囲        | 狭い（利用直後の満足度が主）             | 広い（認知 → 比較 → 購入 → 利用 → サポート…）    |
https://www.hrbrain.jp/media/human-resources-development/cokyakutaikenn#heading-0

## なぜ「CX」が重要とされているか（背景）
- ### 情報取得のハードルが下がった  
    　今は誰でもネットやSNSで情報を得られるから、単に「買って満足」という構造では通用しづらい。
- ### 価値観の変化  
    　「物を所有することより、体験すること」が重視され始めており、体験そのものが価値になっている。
- ### サブスクリプションモデルの普及  
    　継続課金型サービスでは、契約継続を促すには、購入後（利用開始後）の体験が極めて重要になる。

## 成功要因の分析

### 1. **適切な役割分担**
- 人間：創造性、共感、判断力、専門知識が必要な領域
- デジタル：効率性、一貫性、24時間対応、データ処理が求められる領域
### 2. **シームレスな連携**
- 人間とデジタルの間で情報がスムーズに受け渡される仕組み
- 顧客が意識することなく、最適なサポートを受けられる体験設計
### 3. **継続的な改善**
- 顧客フィードバックに基づく人間とデジタルの役割の最適化
- AIと人間スタッフの協働による学習効果の最大化
