## **津田沼 ⇄ 竹田城跡(兵庫県朝来市)の交通費見積もり**

### **基本情報**

- **竹田城跡**: 兵庫県朝来市にある標高353.7mの山城跡
- **別名**: 「日本のマチュピチュ」「天空の城」
- **最寄駅**: JR播但線 竹田駅(駅から徒歩約40分または天空バス利用)

### **基本ルート**

```
津田沼 → 東京駅 → 姫路駅(新幹線) → 竹田駅(JR播但線) → 竹田城跡
```

---

## **1. 新幹線 + 在来線(最速・定番)**

### **ルート**

津田沼 → 東京駅 → 姫路駅(新幹線のぞみ) → 竹田駅(JR播但線) → 竹田城跡

### **料金**

- **津田沼 ⇄ 東京駅**: 往復 約1,000円
- **東京 ⇄ 姫路**:
    - のぞみ指定席: 片道16,570円 × 2 = **33,140円**
    - ひかり指定席: 片道15,730円 × 2 = **31,460円**
    - 自由席: 片道15,400円 × 2 = **30,800円**
- **姫路 ⇄ 竹田**: JR播但線 片道1,170円 × 2 = **2,340円**
- **竹田駅 ⇄ 竹田城跡**: 天空バス 片道300円 × 2 = **600円**(徒歩なら無料)

**往復合計: 34,740円〜37,080円**

### **所要時間**

- 片道: 約5時間〜5時間30分

**リンク**

- [駅探 東京→姫路](https://ekitan.com/transit/shinkansen/section/sf-2590/st-5884)
- [駅探 姫路→竹田](https://ekitan.com/transit/fare/sf-5884/st-5547)
