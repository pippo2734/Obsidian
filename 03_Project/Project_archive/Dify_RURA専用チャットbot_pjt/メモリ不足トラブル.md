1. 発生日時  
📅 2025/3/23

2. 現象  
メモリが不足しているため、このページはひらけません　と表記されソフトが強制的に閉じる

3. 再現手順（分かる範囲で）

4. 解消方法 / 対応策（分かる場合）

対策内容 説明 優先度

- タブを減らす 不要なブラウザタブを閉じてメモリ使用を減らします。 高
- 他アプリを終了する Teams、Excel、Zoomなどの他の重いアプリを終了することで、メモリに余裕を持たせます。 高
- パソコンを再起動する 一時的にメモリが開放され、安定して動作するようになります。 高
- Chrome拡張機能を減らす メモリを多く消費している拡張機能を無効化・削除することで、動作が軽くなる可能性があります。 中
- タスクマネージャーで確認 Ctrl + Shift + Escで起動し、メモリ使用量の高いアプリやプロセスを特定して終了します。 中
- キャッシュを削除する Chromeの設定 → プライバシーとセキュリティ → 閲覧履歴データの削除からキャッシュを削除します。 低
- Chromeを最新に更新 最新バージョンにすることで、パフォーマンスや安定性が向上する可能性があります。 低
- メモリを増設する PCの物理メモリ（RAM）を増やすことで、将来的な安定動作が期待できます。 低

  

📌 備考：  
このエラーは特に、画像や動画の多いページを複数開いていたり、大規模なWebアプリケーションを利用している場合に発生しやすいです。
