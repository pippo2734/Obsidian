# 条件
- 読者が「自分も読んでみたい」と思う構成にする  
- 5冊それぞれに「概要＋おすすめ理由＋刺さる一文」を入れる  
- 最後にまとめ（読者の行動を促す一文）を入れる  
- 全体のトーンはフレンドリーかつ誠実  
- 本文はMarkdown形式で出力する  
- 1冊ごとに見出し（##）をつける  

# 出力フォーマット
1. タイトル案（3案）
2. リード文（導入）
3. 本紹介パート（5冊分）
　- 書籍タイトル
　- 概要（2〜3行）
　- おすすめ理由（共感・気づき・実用性など）
4. まとめ（読者に行動を促す一言）
