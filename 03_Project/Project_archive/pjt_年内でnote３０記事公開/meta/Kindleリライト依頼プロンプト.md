# Kindleリライト依頼プロンプト

## 目的
記事ファイル内で紹介されている本について、09_Kindleフォルダ内の対応するハイライトファイルを参照し、その内容を基に記事の各セクション（概要、おすすめ理由、刺さる一文）をより具体的で魅力的な内容にアップデートする。

## 使用手順

1. **対象ファイルを指定**
   - 記事ファイルのパスを指定
   - 09_Kindleフォルダのパスを指定

2. **記事ファイルを確認**
   - 記事内で紹介されている本のタイトルを確認
   - 各本のセクション構成（概要、おすすめ理由、刺さる一文）を確認

3. **対応するハイライトファイルを検索**
   - 09_Kindleフォルダ内で、記事内の本タイトルと一致する（または類似する）ファイルを検索
   - ファイル名の一部が一致する場合も含める（例：「0秒思考」と「ゼロ秒思考」）

4. **ハイライト内容を確認**
   - 見つかったハイライトファイルの内容を読み込む
   - Highlightsセクション内の重要な引用や洞察を抽出

5. **記事をアップデート**
   - 各本のセクションについて、ハイライトの内容を参考に以下を更新：
     - **概要**: 必要に応じて修正・補足
     - **おすすめ理由**: ハイライトから引用した具体的な洞察や方法論を追加
     - **刺さる一文**: ハイライトから適切な引用を選び、より具体的で魅力的な一文に更新

6. **リード文とまとめの強化**
   - ハイライトから得られた共通の視点や洞察を反映
   - 「書くことで考える」などの重要なコンセプトを追加

## アップデートの方針

### おすすめ理由セクションの更新方針
- ハイライトから引用した具体的な方法論や洞察を追加
- 「なぜこの本がおすすめなのか」をより明確に説明
- ハイライトの内容を自然な文章に組み込む

### 刺さる一文の更新方針
- ハイライトから最も印象的で、読者の心に響く一文を選ぶ
- 50〜100字程度の具体的な引用を選ぶ
- 単なる抽象的な表現ではなく、具体的な方法論や洞察を含む一文を選ぶ

### リード文・まとめの更新方針
- ハイライトから得られた共通の視点やコンセプトを反映
- 全体を通して伝えたいメッセージを明確にする
- 読者の行動を促す内容を追加

## 注意事項

1. **ファイル名の一致**
   - 完全一致しない場合でも、タイトルの一部が一致すれば対応ファイルとして扱う
   - 例：「0秒思考」↔「ゼロ秒思考」、「TAKE NOTES!」↔「TAKE NOTES!――メモで...」

2. **ハイライトの活用**
   - ハイライトが少ない場合でも、見つかった内容を最大限活用する
   - ハイライトが見つからない本については、元の内容を維持する

3. **自然な文章にする**
   - ハイライトの引用をそのまま貼り付けるのではなく、自然な文章に組み込む
   - 読者にとって分かりやすく、魅力的な文章にする

4. **元のトーンを維持**
   - 記事の元のトーンやスタイルを維持する
   - 過度に変更しすぎない

## 使用例

```
@思考が整理できる！効果的なノート術とメモ術5選.md @09_Kindle にタイトルと一致するハイライトを参考に文章をアップデートしてください
```

このプロンプトを実行すると：
1. 記事ファイル内の5冊の本を確認
2. 09_Kindleフォルダ内で対応するファイルを検索
3. 見つかったハイライトを参考に各セクションを更新
4. リード文とまとめにも共通の視点を反映

## 期待される成果

- ハイライトの具体的な内容が反映された、より魅力的な記事
- 読者にとってより参考になる情報が含まれた記事
- 本の本質的な価値が伝わる記事
