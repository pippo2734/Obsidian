# note記事コンテンツ作成・最適化 統合プロンプト

このプロンプトは、note記事の作成から最適化、SNS投稿用コンテンツ生成までを一括で実行します。

**✨ このプロンプトには以下が統合されています：**
- ✅ note記事編集プロンプト（note作成プロンプトVel2.0のスタイル）
- ✅ サムネイル生成プロンプト（完全版）
- ✅ X投稿文生成プロンプト（パターン1・完全版）

**1回の実行で全て完了します。別途他のプロンプトファイルを参照する必要はありません。**

## 🎯 実行内容

以下の5つのステップを自動的に実行します：

1. **記事ファイルの読み込みと分析**
2. **Kindleハイライトの検索と参照**
3. **note作成プロンプトVel2.0に基づいた記事編集**
4. **サムネイル生成プロンプトの作成**（完全版・記事に合わせてカスタマイズ）
5. **X投稿文生成プロンプトの作成**（完全版・記事に合わせてカスタマイズ）

---

## 📋 使用方法

### ステップ1: 記事ファイルを指定

以下の形式で記事ファイルのパスを指定してください：

```
@記事ファイル名.md
```

例：
```
@判断力が劇的に向上！優れた意思決定を学ぶ5冊.md
```

### ステップ2: このプロンプトを実行

以下のコマンドを1回実行するだけで、記事の編集からサムネイル・X投稿文生成プロンプトの作成まで全て完了します：

```
@記事ファイル名.md @note統合_記事コンテンツ作成・最適化_統合プロンプト.md を参照して、以下の作業を順番に実行してください：

1. 記事ファイルを読み込んで、紹介されている本のタイトルを抽出
2. 09_Kindleフォルダ内で各本に対応するハイライトファイルを検索
3. 見つかったハイライトを参照しながら、note作成プロンプトVel2.0のスタイルに基づいて記事を編集：
   - リード文を共感→信頼→メリットの3ステップ構成に
   - 各本の紹介に具体的な場面、Before→After、小さな実践報告、読者への問いかけを追加
   - 「私っぽさ」を出す7要素を意識したトーンに調整
   - 一文40文字前後、語尾のバリエーションを意識
4. 記事と同じフォルダに「サムネイル生成プロンプト.md」を作成：
   - 記事のタイトルとテーマを分析
   - サムネイル生成プロンプトの完全版を作成（Composition、Text layout、Typography & styleを含む）
   - テーマ、小見出し、メインタイトル、サブコピーを記事に合わせて設定
5. 記事と同じフォルダに「X投稿文_パターン1生成プロンプト.md」を作成：
   - 記事のタイトル、紹介する本、テーマを分析
   - X投稿文生成プロンプトの完全版を作成（条件、出力フォーマット、ハッシュタグの選び方を含む）
   - 記事情報セクションに記事タイトル、各本のタイトルと簡潔な説明、テーマを記載
```

**重要：** このプロンプトには、サムネイル生成プロンプトとX投稿文生成プロンプトの完全な内容が含まれています。別途参照する必要はありません。

## 🔄 実行フロー詳細

### ステップ1: 記事ファイルの読み込みと分析

- 記事ファイルを読み込む
- 記事タイトルを抽出
- 紹介されている本のタイトルを抽出（通常5冊）
- 各本のセクション構成を確認

### ステップ2: Kindleハイライトの検索

- `09_Kindle`フォルダ内で各本に対応するハイライトファイルを検索
- ファイル名の一部一致も含める（例：「0秒思考」↔「ゼロ秒思考」）
- 見つかったハイライトファイルを読み込む
- Highlightsセクションから重要な引用を抽出

### ステップ3: 記事の編集

**note作成プロンプトVel2.0の要件に基づいて：**

#### リード文の編集
- 共感→信頼→メリットの3ステップ構成に変更
- 150〜200字程度に調整
- 等身大の一人称（「私も以前は同じでした」）を追加
- 謙虚さを表現（「勝手にご紹介させていただきますが」）

#### 各本の紹介セクションの編集
- **具体的な場面**を追加（会議、朝の通勤、仕事の合間など）
- **Before→After**の体験談を追加（誤解→気づき）
- **小さな実践報告**を追加（「今では、...するようにしています」）
- **読者への問いかけ**を追加（「こんな経験、ありませんか？」）
- ハイライトから引用した具体的な言葉を追加
- 一文40文字前後、語尾のバリエーションを意識

#### まとめセクションの編集
- 感情＋行動＋余韻の構成に変更
- 読者への問いかけとコメント依頼を追加

### ステップ4: サムネイル生成プロンプトの作成

記事と同じフォルダに `サムネイル生成プロンプト.md` を作成します。

**作成内容：**

記事のタイトルとテーマを分析し、以下の完全なサムネイル生成プロンプトを作成してください：

```markdown
Create a stylish YouTube/Note thumbnail in a clean and minimal lifestyle design.
The theme is: 「{記事のテーマ}」  ← 記事のテーマに置き換え（例: 読書、思考法、意思決定など）

### Composition:
- Bright white or light beige desk background with natural soft lighting.
- Items related to the theme on the desk (e.g., books, coffee cup, laptop, keyboard, or other matching props).
- A human hand or partial gesture (like holding a cup or giving thumbs-up) can appear for warmth.
- Add elegant Japanese text in the center.

### Text layout:
- Top small heading: 「{小見出し}」  ← 記事に適した小見出しを生成
- Middle large bold title: 「{メインタイトル}」  ← 記事タイトル
- Bottom small subtext: 「{サブコピー}」  ← 記事の内容に基づいたサブコピーを生成

### Typography & style:
- Clean, modern Japanese fonts (similar to MUJI or minimal magazines)
- White, beige, and light gray color palette
- Natural and calming atmosphere, slightly blurred background
- No heavy contrast, no clutter
- Aspect ratio: 16:9

### Example variables:
{テーマ}: {記事のテーマ}
{小見出し}: {適切な小見出し}
{メインタイトル}: {記事タイトル}
{サブコピー}: {適切なサブコピー}
```

**注意点：**
- 記事のテーマを分析して、適切なテーマ名を設定
- 小見出しは記事の内容に合った魅力的な文言を生成（例：「本当に役立った」「おすすめしたい」など）
- サブコピーは記事の価値を簡潔に伝える文言を生成

### ステップ5: X投稿文生成プロンプトの作成

記事と同じフォルダに `X投稿文_パターン1生成プロンプト.md` を作成します。

**作成内容：**

記事のタイトル、紹介する本、テーマを分析し、以下の完全なX投稿文生成プロンプトを作成してください：

```markdown
# X投稿文 パターン1（問題提起型）生成プロンプト

あなたはX（旧Twitter）でnote記事の拡散を担当するソーシャルメディアマーケターです。
note記事をXで共有するための、インプレッションが上がる投稿文を作成してください。

## 記事情報

記事タイトル: {記事タイトル}

紹介する本:
1. {本1のタイトル}：{簡潔な説明}
2. {本2のタイトル}：{簡潔な説明}
3. {本3のタイトル}：{簡潔な説明}
4. {本4のタイトル}：{簡潔な説明}
5. {本5のタイトル}：{簡潔な説明}

テーマ: {記事のテーマ}

## 条件

- **形式**: 問題提起型（読者の悩みから始まる）
- **文字数**: 280文字以内（リンク除く）
- **構成**: 
  1. 問題提起（読者の悩みを2つ程度列挙）
  2. 解決策の提示（簡潔に）
  3. 本4選のリスト表示（箇条書き）
  4. note記事への誘導
  5. インプレッションが上がるハッシュタグ
- **トーン**: 親しみやすく、共感しやすい。読者の悩みに寄り添う
- **エモジ**: 適度に使用（👇📚など）

## 出力フォーマット

以下のフォーマットに従って作成してください：

```
【問題提起（2行程度）】
「⚪︎⚪︎...」
「⚪︎⚪︎...」

【解決策の提示】
実は、⚪︎⚪︎は⚪︎⚪︎で劇的に改善できます。

【記事タイトル】をまとめました👇

【本4選のリスト】
・⚪︎⚪︎：⚪︎⚪︎
・⚪︎⚪︎：⚪︎⚪︎
・⚪︎⚪︎：⚪︎⚪︎
・⚪︎⚪︎：⚪︎⚪︎

詳細はnoteで👇
[note記事へのリンク]

【ハッシュタグ】
#読書 #思考法 #フレームワーク #アイデア出し #ビジネス書 #note #書評 #問題解決 #クリエイティブ思考 #学習 #自己啓発 #生産性向上 #発想力 #ロジカルシンキング #仕事術 #スキルアップ
```

## ハッシュタグの選び方

記事のテーマに応じて、以下のハッシュタグから適切なものを選んでください：

### 必須タグ
- #note（note記事投稿）
- #読書（読書関連）

### テーマ別タグ
- **思考法系**: #思考法 #フレームワーク #ロジカルシンキング #クリエイティブ思考
- **自己啓発系**: #自己啓発 #学習 #スキルアップ #生産性向上
- **ビジネス系**: #ビジネス書 #仕事術 #問題解決
- **アイデア系**: #アイデア出し #発想力
- **その他**: #書評

## 注意事項

- 文字数は必ず280文字以内にする
- 読者の悩みを具体的に表現する
- 本の紹介は簡潔に（各本1行以内）
- ハッシュタグは15〜20個程度が目安
- リンク部分は `[note記事へのリンク]` として残す
```

**注意点：**
- 記事タイトルと紹介する本の情報を正確に記載
- 記事のテーマを分析して、適切なテーマ名を設定
- 各本の簡潔な説明は、記事内の紹介文から抽出または要約

## 📝 注意事項

1. **ハイライトが見つからない本について**
   - 元の内容を維持しつつ、note作成プロンプトVel2.0のスタイルに合わせて編集

2. **ファイル名の一致**
   - 完全一致しない場合でも、タイトルの一部が一致すれば対応ファイルとして扱う

3. **自然な文章**
   - ハイライトの引用をそのまま貼り付けるのではなく、自然な文章に組み込む

4. **トーンの維持**
   - 記事の元のトーンを維持しつつ、より魅力的な内容に改善
