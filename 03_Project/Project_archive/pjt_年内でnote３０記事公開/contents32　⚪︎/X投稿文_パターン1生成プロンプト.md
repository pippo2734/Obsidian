# X投稿文 パターン1（問題提起型）生成プロンプト

あなたはX（旧Twitter）でnote記事の拡散を担当するソーシャルメディアマーケターです。
note記事をXで共有するための、インプレッションが上がる投稿文を作成してください。

## 記事情報

記事タイトル: 情報に振り回されない！メディアリテラシーを高める4冊

紹介する本:
1. エビデンスを嫌う人たち：エビデンス（科学的証拠）の重要性を解説。証拠を無視する心理と、エビデンスに基づいて判断することの重要性が詳しく説明されている
2. 事実はなぜ人の意見を変えられないのか？：情報と認識の関係を解説。なぜ人は事実を受け入れず、自分の意見を変えないのかが詳しく説明されている
3. 統計学が最強の学問である：データで判断する習慣を解説。統計学を使って、情報の真偽を見極める方法が詳しく説明されている
4. 知っているつもり〜無知の科学〜：無知の認識を解説。自分が知っていると思っていることと、実際に知っていることのギャップを理解することが詳しく説明されている

テーマ: メディアリテラシー・情報リテラシー

## 条件

- **形式**: 問題提起型（読者の悩みから始まる）
- **文字数**: 280文字以内（リンク除く）
- **構成**: 
  1. 問題提起（読者の悩みを2つ程度列挙）
  2. 解決策の提示（簡潔に）
  3. 本4選のリスト表示（箇条書き）
  4. note記事への誘導
  5. インプレッションが上がるハッシュタグ
- **トーン**: 親しみやすく、共感しやすい。読者の悩みに寄り添う
- **エモジ**: 適度に使用（👇📚など）

## ハッシュタグの選び方

記事のテーマに応じて、以下のハッシュタグから適切なものを選んでください：

### 必須タグ
- #note（note記事投稿）
- #読書（読書関連）

### テーマ別タグ
- **思考法系**: #思考法 #フレームワーク #ロジカルシンキング #クリエイティブ思考
- **自己啓発系**: #自己啓発 #学習 #スキルアップ #生産性向上
- **ビジネス系**: #ビジネス書 #仕事術 #問題解決
- **アイデア系**: #アイデア出し #発想力
- **その他**: #書評

## 注意事項

- 文字数は必ず280文字以内にする
- 読者の悩みを具体的に表現する
- 本の紹介は簡潔に（各本1行以内）
- ハッシュタグは15〜20個程度が目安
- リンク部分は `[note記事へのリンク]` として残す
