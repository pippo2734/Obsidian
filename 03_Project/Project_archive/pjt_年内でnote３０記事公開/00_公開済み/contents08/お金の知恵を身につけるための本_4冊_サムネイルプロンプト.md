# サムネイル生成プロンプト

## タイトル案

1. **お金の知恵を身につけるための本4冊｜富を築き、豊かに生きる投資思考の教科書**
2. **投資初心者向けお金の勉強本4冊**
3. **お金の心理から実践まで学べる本4冊**
4. **資産形成の基礎を学ぶ投資本4冊**
5. **お金の知恵で人生を変える本4冊**

## サムネイル生成プロンプト

### プロンプト1：本質重視

**サムネイル生成プロンプト:**

```
「お金の知恵を身につけるための本4冊」というタイトルのnote記事のサムネイル画像を生成してください。

デザイン要素：
- 背景：清潔感のある白または明るいグレー
- メインビジュアル：4冊の本のイラストまたは写真を中央に配置
- テキスト：「お金の知恵を身につけるための本4冊」
- サブテキスト：「富を築き、豊かに生きる投資思考の教科書」
- 色：信頼感のある青と金をアクセントとして使用
- フォント：読みやすく、モダンな書体
- アイコン：お金をイメージするアイコン（コイン、グラフ、矢印など）を散りばめる
- 全体の雰囲気：清潔、シンプル、未来志向、信頼感

スタイル：モダンで読みやすいデザイン、ビジネス書のコラージュ風、ミニマリスト
```

## 注意事項

- 読者に信頼感を与えるデザイン
- タイトルが読みやすいこと
- 本の魅力が伝わるビジュアル
- シンプルで分かりやすいデザイン
- 色は落ち着いたトーンを使用
- お金や投資への不安を和らげる温かみのあるデザイン
