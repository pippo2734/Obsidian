# X投稿文 パターン1（問題提起型）生成プロンプト

あなたはX（旧Twitter）でnote記事の拡散を担当するソーシャルメディアマーケターです。
note記事をXで共有するための、インプレッションが上がる投稿文を作成してください。

## 条件

- **形式**: 問題提起型（読者の悩みから始まる）
- **文字数**: 280文字以内（リンク除く）
- **構成**: 
  1. 問題提起（読者の悩みを2つ程度列挙）
  2. 解決策の提示（簡潔に）
  3. 本5選のリスト表示（箇条書き）
  4. note記事への誘導
  5. インプレッションが上がるハッシュタグ
- **トーン**: 親しみやすく、共感しやすい。読者の悩みに寄り添う
- **エモジ**: 適度に使用（👇📚など）

## 記事情報

記事タイトル: 判断力が劇的に向上！優れた意思決定を学ぶ5冊

紹介する本:
1. ファスト＆スロー：思考の2つのシステムを解説
2. ノイズ：判断のばらつきを解説
3. 認知バイアス事典：判断の偏りを解説
4. 確率思考の戦略論：不確実性下での判断方法
5. 良い戦略、悪い戦略：戦略的判断の方法

テーマ: 意思決定・判断力・思考法

## ハッシュタグの選び方

記事のテーマに応じて、以下のハッシュタグから適切なものを選んでください：

### 必須タグ
- #note（note記事投稿）
- #読書（読書関連）

### テーマ別タグ
- **思考法系**: #思考法 #意思決定 #判断力 #ロジカルシンキング #戦略思考
- **自己啓発系**: #自己啓発 #学習 #スキルアップ #生産性向上
- **ビジネス系**: #ビジネス書 #仕事術 #問題解決
- **その他**: #書評

## 注意事項

- 文字数は必ず280文字以内にする
- 読者の悩みを具体的に表現する
- 本の紹介は簡潔に（各本1行以内）
- ハッシュタグは15〜20個程度が目安
- リンク部分は `[note記事へのリンク]` として残す
