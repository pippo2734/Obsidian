# 本紹介アウトプット用プロンプト

## 使用方法

このプロンプトを使用して、週間べ氏の本紹介コーナー用の記事を生成してください。

## プロンプトテンプレート

```
以下の情報を基に、週間べ氏の本紹介コーナー用の記事を作成してください。

【本の情報】
- 書籍名：[書籍名を入力]
- 著者：[著者名を入力]
- 研究機関・肩書き：[例：コロンビア大学のモチベーション心理学者、ハーバード大学の心理学者など]
- Amazonリンク：[Amazonアフィリエイトリンクを入力]

【本の特徴・ポイント】
- ページ数：[少ない/多い/中程度など]
- 読みやすさ：[読みやすい/シンプル/実践しやすいなど]
- 特に注目したいポイント：[全人類に実践してほしいテクニック、最も重要な気づきなど]
- 本のテーマ：[目標達成、お金の使い方、習慣化など]

【読者への訴求ポイント】
- ターゲット読者の悩み：[例：目標を立てても3日坊主で終わってしまう、続けたいことが続かない]
- 本を読むべき理由：[例：科学的に証明されたメソッド、実践しやすい方法など]

【記事の構成要件】
- 詳細な内容はインフォグラフィックで伝えるため、本文は3行程度で簡潔にまとめる
- 特に重要なポイントは1つに絞って強調する
- 読者に共感できる表現を使う
- 実践しやすさをアピールする
```

## 記事構成テンプレート

### 1. 冒頭の挨拶（固定）

```

週間べ氏の本紹介コーナー！

正直RURA拡大でめちゃくちゃ大変なのですが、そんな時でも継続できる方法を考えて続けることに価値を感じて、今日はRURA拡大第１弾ですが懲りずにやります♩
```

### 2. 今回紹介する本のテーマ（変動）

```
さて今回紹介するのは
[読者に響く問題提起やタイミングを含めた本のテーマ紹介]
```

**例：**
- 「目標を立てても3日坊主で終わってしまう、続けたいことが続かない——そんな悩みを抱えている方にぜひ読んでほしい「目標達成のための科学的メソッド」について書かれた本です。」
- 「ちょうどボーナスも出ているタイミングなので、今回ご紹介するのは「幸せになるお金の使い方」について書かれた本です。」

### 3. Amazonリンク（固定形式）

```
[Amazonで購入する](https://amzn.to/3xXxXxX)
```

### 4. 本の紹介（3行程度で簡潔に）

```
[研究機関・肩書き]、[著者名]が研究で明らかにした「[書籍のテーマ]」について書かれた本です。[ページ数や読みやすさなどの特徴]。すぐに実践できるのが魅力です。

この本で特に注目したいのは、**[最も重要なポイント]**です。[具体的な説明と研究結果]。これは全人類に実践してほしいテクニックです。

[本の価値のまとめ]。続けられなかったのは、方法を知らなかっただけかもしれません。
```

**構成のポイント：**
- **1行目**：本の紹介と特徴（ページ数、読みやすさ、実践しやすさ）
- **2行目**：特に注目したいポイント（全人類に実践してほしいテクニックなど）
- **3行目**：本の価値の再確認と読者への共感

### 5. 締めの言葉（固定）

```
気になる方はぜひ本を読んでみて！

『[書籍名]』（[著者名]著）
```

## 作成時の注意事項

### トーン・スタイル
- カジュアルで親しみやすい
- 読者に共感できる表現
- 実践的で具体的
- 簡潔で読みやすい

### 文字数
- 全体で300-500文字程度
- 本の紹介部分は3行程度（詳細はインフォグラフィックで伝える）

### 強調ポイント
- 特に重要なテクニックや気づきは**太字**で強調
- 「全人類に実践してほしい」などの強い訴求を入れる

### 読者への訴求
- 読者の悩みに共感する
- 「続けられなかったのは、方法を知らなかっただけ」などの共感フレーズ
- 実践しやすさをアピール

## カスタマイズポイント

本の内容に応じて、以下のポイントを調整してください：

1. **本の特徴の強調**
   - ページ数が少ない → 「ページ数も少なく、すぐに読める」
   - シンプル → 「シンプルで実践しやすい」
   - 研究に基づいている → 「科学的な研究結果から学べる」

2. **特に注目したいポイント**
   - テクニック系 → 「全人類に実践してほしいテクニック」
   - 気づき系 → 「最も大きな気づきがあったのは」
   - 方法論系 → 「この方法を知るだけで」

3. **読者への訴求**
   - 悩みに共感 → 「続けられなかったのは、方法を知らなかっただけ」
   - 実践しやすさ → 「すぐに実践できるのが魅力」
   - 価値の再確認 → 「この知見を参考に、〜できるのではないかと思います」
