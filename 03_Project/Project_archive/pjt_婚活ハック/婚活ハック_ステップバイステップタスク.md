# 婚活ハック ステップバイステップタスク

## ステップ1：婚活マインドセットを「科学者」に切り替える

### 1.1 行動の習慣化
- [x] **毎日の婚活行動リスト作成** ✅ 2025-11-04
  - マッチングアプリのプロフィール見直し（5分）
  - 新しいコミュニティ検索（10分）
  - 既存のマッチング相手へのメッセージ返信（5分）
  - 婚活関連の情報収集（10分）
- [x] **習慣化の記録開始** ✅ 2025-11-04
  - 毎日の婚活行動を記録するシートを作成
  - 1週間継続できたかチェック
  - 継続できなかった理由を分析し、改善策を検討

### 1.2 [[03_Project/Project_archive/pjt_婚活ハック/婚活相手の絶対条件]]
- [x] **絶対条件の書き出し ✅ 2025-10-22
  - 紙に「絶対に譲れない条件」を全て書き出す
  - 各条件について「なぜ絶対なのか」理由を記載
- [x] **条件の優先順位付け** ✅ 2025-10-22
  - 条件を重要度順に並び替え
  - 上位3つ以外は「希望条件」に変更
- [x] **柔軟性の練習** ✅ 2025-10-22
  - 各条件について「他の魅力で補えるか」検討
  - 実際の出会いで条件を再評価する機会を設ける

### 1.3 「運命の人」幻想からの脱却
- [x] **出会いの捉え方を変える** ✅ 2025-10-22
  - 「仮説と検証の場」として出会いを捉える練習
  - 初対面で全てを判断しない意識付け
- [x] **成長可能性の視点** ✅ 2025-10-22
  - 相手の成長可能性を考える習慣をつける
  - 関係性の中で育むものがあるか検討する練習

## ステップ2：自分の魅力と価値観を「科学的に分析」

### 2.1 魅力の棚卸し
- [x] **魅力の特定** ✅ 2025-10-22
  - 自分の魅力を3つ選ぶ（思いやり、協調性、親切さ、知性、ユーモアなど）
  - 各魅力について具体的なエピソードを書き出す
- [x] **エピソードの整理** ✅ 2025-11-04
  - 職場での経験
  - プライベートでの経験
  - ボランティア活動の経験
  - 友人関係での経験
- [x] **魅力の伝え方練習** ✅ 2025-11-04
  - 各魅力を自然に会話で伝える練習
  - 友人との会話で実際に試してみる

### 2.2 価値観の明確化
- [x] **価値観リスト作成** ✅ 2025-10-22
  - 人生で最も大切にしている価値観を5つリストアップ
  - 例：安定、成長、自由、家族、社会貢献
- [x] **価値観の優先順位** ✅ 2025-10-22
  - 5つの価値観を重要度順に並び替え
  - 各価値観について具体的な行動例を記載
- [x] **価値観の聞き出し練習** ✅ 2025-11-04
  - 友人や知人との会話で相手の価値観を聞き出す練習
  - 自分の価値観との重なりを意識する練習

## ステップ3：婚活戦略を「マーケティング視点」で設計

### 3.1 複数チャネルの活用
- [x] **チャネルリスト作成** ✅ 2025-11-04
  - マッチングアプリ
  - 友人紹介
  - 社会人サークル
  - 趣味のコミュニティ
  - 職場の飲み会
  - セミナー・勉強会
- [x] **時間配分計画** ✅ 2025-11-04
  - 各チャネルに週何時間割くか計画
  - 1週間のスケジュールに組み込む
- [x] **チャネル別戦略** ✅ 2025-11-04
  - 各チャネルでの具体的な行動計画
  - 月1回の効果測定と見直し

### 3.2 プロフィール最適化の実験
- [x] **プロフィール写真の複数パターン作成** ✅ 2025-11-04
  - 明るい写真
  - 自然な笑顔の写真
  - 趣味を表現した写真
  - 控えめな加工を試す
- [x] **自己紹介文の複数パターン作成** ✅ 2025-10-22
  - 簡潔版
  - 詳細版
  - ユーモア重視版
  - 真面目版
- [x] **A/Bテスト実施** ✅ 2025-11-04
  - 各パターンで1週間ずつテスト
  - マッチング数、メッセージ返信率を記録
  - 最も効果的なパターンを特定

### 3.3 KPIの設定と記録
- [x] **KPI設定** ✅ 2025-11-04
  - マッチング数（週目標）
  - メッセージ返信率（目標％）
  - デートに繋がった数（月目標）
- [x] **記録シート作成** ✅ 2025-11-04
  - 週ごとの数値を記録するシート
  - チャネル別の効果測定
- [x] **月次レビュー** ✅ 2025-11-04
  - 数値の分析
  - 戦略の見直しと改善

## ステップ4：初対面での「印象形成とコミュニケーション」を最適化

### 4.1 ファーストメッセージのパーソナライズ練習
- [x] **プロフィール読み込み練習** ✅ 2025-11-04
  - 相手のプロフィールを詳しく読む習慣
  - 興味深い点を3つ特定する練習
- [x] **パーソナライズメッセージ作成** ✅ 2025-11-04
  - 相手固有の話題に触れた質問
  - 相手の趣味や経験への感想
  - コピペではない個別対応
- [x] **メッセージ送信前チェック** ✅ 2025-11-04
  - 相手の名前を正しく書いているか
  - 相手のプロフィール内容に触れているか
  - 自然な会話の流れになっているか

### 4.2 初デート「30分作戦」のシミュレーション
- [x] **ポジティブ話題の準備** ✅ 2025-11-04
  - 趣味について
  - 最近あった楽しいこと
  - 将来の夢や目標
  - 旅行の思い出
- [x] **時間管理練習** ✅ 2025-11-04
  - 30分で話せる話題を整理
  - 会話の流れをシミュレーション
  - 友人との会話で時間を意識する練習
- [x] **デート場所の選定** ✅ 2025-11-04
  - 話しやすい環境
  - 適度な時間制限がある場所
  - 緊急時の避難場所も考慮

### 4.3 質問バンクの作成
- [x] **オープンクエスチョンリスト作成** ✅ 2025-11-04
  - 「最近ハマっていることは何ですか？」
  - 「人生で最も感動した経験は何ですか？」
  - 「理想の休日の過ごし方は？」
  - 「将来の夢や目標は？」
  - 「大切にしている価値観は？」
- [x] **質問の実践練習** ✅ 2025-11-04
  - 友人との会話で質問を試す
  - 自然な会話の流れで質問する練習
  - 相手の反応を見て質問を調整
- [x] **会話の継続テクニック** ✅ 2025-11-04
  - 相手の答えから次の質問を考える練習
  - 共通点を見つける練習
  - 会話が途切れないテクニック

## ステップ5：関係の「成長と見極め」を計画的に行う

### 5.1 複数回デートの見極め練習
- [x] **セカンドチャンスの基準設定** ✅ 2025-11-04
  - 初回で「違う」と感じた理由を分析
  - 再評価すべき点をリストアップ
  - 2回目のデートで確認したい点
- [x] **非交渉条件の確認タイミング** ✅ 2025-11-04
  - 子供の有無
  - 結婚観
  - 将来の住居希望
  - 家族との関係
- [x] **見極めの判断基準** ✅ 2025-11-04
  - 3回デートしても改善されない点
  - 相手の成長意欲
  - 自分との相性

### 5.2 地雷トークの回避訓練
- [x] **避けるべき話題リスト** ✅ 2025-11-04
  - 過去の恋愛
  - 家族の問題
  - 政治・宗教
  - ネガティブな不満
  - お金の話
- [x] **話題切り替えテクニック** ✅ 2025-11-04
  - 「それは難しい話ですね。ところで、最近何か面白いことありましたか？」
  - 「そうですね。話は変わりますが...」
  - 「興味深いですね。それに関連して...」
- [x] **ポジティブ話題への誘導** ✅ 2025-11-04
  - 相手の趣味や興味
  - 楽しい経験
  - 将来の希望
  - 共通の話題

### 5.3 関係性の成長マインドセット
- [x] **成長視点の練習** ✅ 2025-11-04
  - 相手の欠点ではなく長所に注目
  - 「この人とどんな関係性を築けるか」を考える
  - 相手のポジティブな変化に気づく
- [x] **共通点探しの習慣** ✅ 2025-11-04
  - 小さな共通点を見つける練習
  - 共通の趣味や価値観を探す
  - 一緒にできることを考える
- [x] **関係性の評価** ✅ 2025-11-04
  - 月1回の関係性レビュー
  - 成長している点の確認
  - 改善すべき点の特定
