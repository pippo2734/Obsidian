# タグ運用ルール

## 情報源タグ
- #書籍 : 書籍から得た文献ノート
- #記事 : Web記事やニュース
- #MTG : 社内/外部ミーティング
- #Dラボ : Dラボ動画の学び

## テーマタグ
- #心理学 : 心理学に関するアイデア
- #AI活用 : AIに関する学びや応用
- #読書メモ : 本から得たアイデア

## ライフタグ
- #やってみたい事 : 実験・挑戦
- #行きたいところ : 行きたい場所メモ
- #欲しいもの : 物欲ログ
- #感情ログ : 感情メモ・レビュー
- #あとで調べる : 後で消化したいリサーチ課題
- #学び :学んだ事　発見や気づき
- #失敗 :失敗記録　トライアンドエラー
