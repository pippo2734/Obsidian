## Zettelkasten全体構成（Obsidian Vault内の例）

```
Vault（ルート）
├── 00-Meta/      # システム設定、テンプレート、ダッシュボード
├── 01-Daily/     # 日次の記録（デイリーノート）
├── 02-Areas/     # 長期的な責任領域やテーマ
├── 03-Projects/  # 進行中のプロジェクト単位ノート
├── 04-Resources/ # 参照情報（外部資料やクリッピング）
├── 05-Archive/   # 完了・古いノートの保管場所
└── 06-Attachments/# 画像やPDFなど添付ファイル
└── Zettelkasten/
    ├── Fleetings/    # 思いつきなど一時的なメモ
    ├── Literatures/  # 文献ノート（読む情報の要約など）
    ├── Permanents/   # 永久ノート（アイデアの本質や考察まとめ）
    ├── Projects/     # プロジェクト関連ノート
    ├── StructureNotes/ # 構造化ノート（関連ノートをまとめる）
    └── IndexNotes/   # 索引・目次ノート
```

## ノートの役割と運用

- **Fleeting Notes**  
日々の小さなアイデアや気づきの断片。  
→ 後でLiteratureやPermanentに加工する材料[2][3][1]。

- **Literature Notes**  
本や記事、動画などのインプットを自分の言葉でまとめるノート。  
→ 根拠となり、Permanent Note作成の基礎[2][3]。

- **Permanent Notes**  
核となる自分の考えや知見をまとめた自律的なノート。  
→ 他ノートとリンクし、知識ネットワークを形作る[2][1]。

- **Structure Notes**  
関連するPermanent Notesをリンクでまとめ、体系的に整理するノート。  
→ 知識全体の俯瞰とナビゲーションを助ける[1][3]。

- **Index Notes**  
ノート群の索引やテーマ別目次として機能する。  
→ 大量のノートから目的のものを見つけやすくする[1][3]。

## 運用のポイント

- フォルダは多階層にせず、なるべくフラットに近い形で管理する  
- ノート作成は1つのアイデアに1つのノート（１トピック1ファイル）  
- 各ノートは積極的に相互リンクを張ってネットワークを構築する  
- テンプレートとプラグイン（Dataviewなど）の活用で効率アップ  
- 定期的な見直しと新しいリンクの追加を行い知識を進化させる  

## まとめ

ObsidianでのZettelkastenは、「情報収集→メモ作成→アイデア抽出→相互リンク→体系化」を繰り返しながら、知識のネットワークを構築・深化させる方法です。  
フォルダ構成やノートの種類を整理し、テンプレートやプラグインで運用を自動化・効率化するのが鍵となります[2][3][1][4][7]。
