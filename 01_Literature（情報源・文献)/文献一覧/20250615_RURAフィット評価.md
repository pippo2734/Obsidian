
## 📘 カテゴリ①：基盤整備（使わせる準備）

### 評価目的
RURAが「現場で実際に使われる」ための下地を整える取り組みを評価する。まだ稼働していないフェーズだからこそ、“準備の質と丁寧さ”がスコアを左右する。

---

### ① 活用設計（ユースケースの設計）

| 評価 | 状態 |
|------|------|
| 1点  | 活用構想はあるが、資料・形として未整理。 |
| 2点  | 1クラブでの口頭ヒアリングをもとに非公開メモを作成。 |
| 3点  | 少なくとも1クラブでRURA活用ユースケースを明文化・共有。 |
| 4点  | 複数クラブからニーズをヒアリングし、3種以上のユースケースを整理。 |
| 5点  | クラブ別にカスタマイズされたユースケース設計を完了し、現場でのテストも実施済み。 |

---

### ② 資料整備（マニュアル・案内資料の整備）

| 評価 | 状態 |
|------|------|
| 1点  | 資料未作成。説明は都度口頭対応。 |
| 2点  | 基本的な資料を一部作成。共有は限定的。 |
| 3点  | 活用方法・操作説明などのマニュアルを1セット作成し、クラブに共有済。 |
| 4点  | クラブからのフィードバックをもとに資料を更新。質問対応用のQ&Aも併設。 |
| 5点  | クラブ別の状況に応じた複数パターンの資料を整備。動画や図解など多様な形式も活用。 |

---

### ③ 現場連携（クラブとの関係性・窓口構築）

| 評価 | 状態 |
|------|------|
| 1点  | 連携なし。突発的な質問が来るのみ。 |
| 2点  | 担当クラブを把握し、必要時に連絡可能な状態。 |
| 3点  | フロントチーフや副支配人と定例的な連携ルートを確保。月1以上のやり取りがある。 |
| 4点  | クラブ側からも自発的に活用相談が来る状態。信頼関係が構築されている。 |
| 5点  | フィット側の責任者も巻き込み、クラブ主導の導入推進体制が形成されている。 |

---

### 💡補足
- 「少人数だからこそできる丁寧な設計・関係構築」が5点の要件。
- ドキュメントややりとりのログをNotionやTeamsに蓄積しておくと、自己評価や上司評価時の裏付けになる。
