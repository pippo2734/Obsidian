## 3. FLUX設定の初期値（Playground画面）
- **Prompt**：生成したい内容（後述のGPT生成プロンプトを貼る）
- **Seed**：未指定でOK（ランダム）。再現したい時だけ固定
- **Aspect Ratio**：MV用は 16:9（横長） または 9:16（縦動画）を選択
- **Output Format**：`png` または `jpeg`（画質重視なら `png`）
- **Raw**：**ON推奨**（プロンプトへの忠実性が上がる）
- **Num Images**：固定（1）
- **Safety系**：モデル仕様で変更不可の項目はそのまま
- **Requests**：履歴。良かったプロンプトは必ず保存/複製

---

## 4. プロンプトはAIに作らせる（GPTs活用）
> 自作より **速い・ブレない・反復しやすい**。  
> 例：**Flux Prompt Pro**（GPTs）を使用

- [x] GPTに**要件を短く**伝える（例：「朝の下灘駅／旅立ち／映画的」） ✅ 2025-09-12
- [x] **5パターン**ほど英語プロンプトを出してもらう（英日併記だと便利） ✅ 2025-09-12
- [x] 1つ選んで **FLUXに貼って生成**（Raw=ON） ✅ 2025-09-12
- [x] 出力を見て **足りない言葉だけ追記**（光／色／カメラワークなど） ✅ 2025-09-12

**例・最小指示（GPTへの投げ方）**  
- 「FLUX 1.1 pro ultra向け。16:9、Raw前提。朝の下灘駅で“これから旅立つ”情緒。写実×少し幻想的。衣装・小物は固定。映画的ライティング。5案。」

---

## 5. 生成 → 評価 → 改善のループ（最短回し）
1. **初回生成**：候補プロンプトの1つをそのまま貼って出力
2. **差分指示**：良し悪しを言語化  
   - 「空の色をもっと淡く」「逆光で」「被写界深度を浅く」「Lens flare控えめ」
3. **1〜2語ずつ**足す（盛りすぎると破綻しやすい）
4. **Seed固定**で微修正、**Seed変更**でバリエーション探索
5. **良作は即DL＆プロンプト保存**（Requestsや自分のノートに転記）

---

## 6. 画風・キャラ・構図の切替（同一世界観のまま）
- **画風だけ変更**：  
  「watercolor」「cel-shaded anime」「photorealistic」「Ghibli-inspired」などを追加
- **キャラ設定変更**：  
  髪・装飾・服・表情・年齢感などを**短文で置換**（他は触らない）
- **構図変更**：  
  `wide shot / medium / close-up / POV / low angle / high angle / fisheye / over-the-shoulder / rule of thirds / leading lines` など **カメラ語彙**を明示

**例（構図リライト）**  
- 「自撮り風、fisheye、見下ろし視点、被写界深度浅め、前景に手を大きく」

- [x] 再利用時の呼び出し例 ✅ 2025-09-20

## 8. NSFW回避の言い換え（生成が弾かれる時）
- **年齢・武器・過激表現**があると失敗しやすい  
  → **抽象化**して言い換える
  - 「銃」→「光のエネルギーを放つ」「魔法の閃光」
  - 「流血」→「光の粒子」「破片／砂塵」
  - 「未成年＋危険物」→**排除**または年齢曖昧化・安全演出に変更
- GPTに「**NSFWに引っかからない言い換え**で再構成して」と依頼
