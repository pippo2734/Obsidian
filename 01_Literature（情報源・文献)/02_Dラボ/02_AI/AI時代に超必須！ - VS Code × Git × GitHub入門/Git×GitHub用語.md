## GitHubの用語

リポジトリ
- プロジェクト毎の箱のようなもの

コミット
- あとで戻れる「履歴のセーブ」のようなもの
- こまめにコミットが大事
	- 作業内容単位でセーブをする

プッシュ
- GitからGitHubに送信すること
	- 変更の共有
	- 同期
	- バージョン管理
- 基本的な使い方
	1. ローカルでコミット
	2. ブランチを指定してプッシュ
	3. 最新状態をプル

- プル：ネット上　→ 自分のPCに取り込む
- プッシュ：自分のPC 　→ネット上に送る

branch　ブランチ
- 安全な並行世界


イシュー
- 掲示板みたいなもと
- 課題やバグをここに載せる
	- backlogに似ていそう
