# NotebookLMで社内資料に活用できるインフォグラフィック作成プロンプト集約

NotebookLMの新しいインフォグラフィック機能を活用して、社内資料として使えるプロンプトを目的別に集約しました。2025年11月に追加されたこの機能は、Nano Banana Pro（Gemini 3 Pro Image）を活用し、日本語テキストも高精度に描画できます。

## 📋 基本設定の理解

### インフォグラフィックのカスタマイズ項目

NotebookLMのインフォグラフィック作成では、以下の設定が可能です：

|設定項目|選択肢|推奨用途|
|---|---|---|
|**詳細レベル**|簡潔 / 標準 / 詳細（ベータ版）|簡潔：SNS投稿、標準：社内報告、詳細：研修資料|
|**レイアウト**|横向き（16:9）/ 縦向き（9:16）/ 正方形（1:1）|横向き：プレゼン、縦向き：スマホ、正方形：SNS|
|**言語**|日本語含む多言語対応|社内資料は日本語推奨|

## 🎯 目的別プロンプトテンプレート集

### 1. 会社紹介・企業概要資料

**用途：** 新入社員研修、取引先紹介、採用活動

**推奨設定：**

- 詳細レベル：標準
- レイアウト：横向き（16:9）

**プロンプト例（日本語）：**

```
コーポレートカラーの青（#003366）を基調とした会社紹介インフォグラフィックを作成してください。

レイアウト要件：
- 上部：会社名を大きく太字で表示
- 中央部：売上高・従業員数・事業領域の3つの主要指標を、アイコン付きの個別ボックスで表示
- 下部：創業年と企業理念を小さめの文字で配置

デザインスタイル：プロフェッショナルで信頼感のあるビジネス調
強調点：3つの主要指標を最も大きな視覚要素にする
```

```

- ステップ間の流れを矢印で明確に表示
- 各ステップの所要時間を記載
- 重要な注意点を別色で強調

デザインスタイル：シンプルで分かりやすい
視覚要素：フローチャート形式で左から右（または上から下）へ展開
```

## 💡 プロンプト作成のコツ

### 効果的なプロンプトの5要素

1. **対象者**：誰向けか（役員、顧客、一般向け等）
2. **目的**：何のため（提案、報告、教育等）
3. **構成**：何枚、どんな順番
4. **トーン**：どんな雰囲気（ビジネス、カジュアル、アカデミック等）
5. **強調点**：何を重視（数字、ストーリー、ビジュアル等）

### プロンプトの段階的改善方法

**ステップ1：** まずNotebookLMのチャットで壁打ち

```
「〇〇についてのインフォグラフィックを作りたい。どのようなプロンプトが効果的か提案してください」
```

**ステップ2：** 提案されたプロンプトをレビュー

**ステップ3：** カスタマイズして生成

**ステップ4：** 結果を確認し、必要に応じて調整

## ⚠️ 注意事項と制約

### 現在の制限事項

1. **出力形式**：PNG形式のみ（編集不可）
2. **文字化け**：詳細モードでは文字崩壊が発生することがある
3. **再編集**：生成後の直接編集機能はなし
4. **NotebookLMロゴ**：生成物にロゴが表示される

### 回避策

- **文字化け対策**：プロンプトで「テキストラベルを含まず、後から追加できるようスペースを確保」と指示
- **編集対応**：生成後、PowerPointやCanvaで微調整する前提で設計
- **品質向上**：ソースとなる資料の質を高める
