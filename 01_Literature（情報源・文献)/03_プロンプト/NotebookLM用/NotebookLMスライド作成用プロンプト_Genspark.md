## **NotebookLMスライド作成の推奨プロンプト集**

### **🎯 基本的な構造化プロンプト**

#### **1. 詳細プレゼンテーション作成プロンプト**

```
この資料を7枚のプレゼンテーションに変換してください。

- 各スライドに明確で簡潔なタイトルを付ける
- 各スライドに3〜5個の重要な箇条書きポイントを含める
- 主要なアイデアに焦点を当て、フィラーを避ける
- シンプルでスライドに適した言語を使用（段落全体ではなく）
- 論理的な構成:
  1. タイトル/導入スライド
  2〜6. メインコンテンツスライド
  2. 結論または重要なポイント
- ポイントの繰り返しを避け、関連するアイデアをグループ化
- 必要に応じて、ビジュアル（チャート、画像、アイコン）の提案を含める
- GoogleスライドやPowerPointにコピーしやすい形式で出力
```

[XDA Developers](https://www.xda-developers.com/notebooklm-prompts-to-make-presentation-slides/)

#### **2. 問題-解決-結果構造プロンプト**

```
問題-解決-結果構造を使用してスライドアウトラインを生成してください。

- コンテンツを3つの核心セクションに分ける:
  - 問題または課題
  - 提案または実装された解決策
  - 結果、成果、または影響
- 各セクションに情報の深さに応じて1〜2枚のスライドを作成
- 各スライドに明確で簡潔なタイトルを付ける
- 類似または補完的なポイントをグループ化して論理的な流れを保つ
- プレゼンテーションに適したシンプルな言語を使用
- 該当する場合、ビジュアルの追加場所を提案（結果のチャート、問題の写真など）
- GoogleスライドやPowerPointに転送しやすい形式で出力
```

### **📊 データ・スプレッドシート分析用プロンプト**

#### **3. Excel/スプレッドシートデータのスライド化**

```
スプレッドシートまたはテーブル重視の文書をアップロードしました。データを明確なプレゼンテーションアウトラインに変換してください。

- 数値のキーパターン、外れ値、またはトレンドを特定
- 大幅な増加、減少、相関関係などの注目すべき洞察を強調
- 洞察を3〜5の論理的なセクションにグループ化（例：売上トレンド、トップ製品、地域パフォーマンス）
- 各セクションごとに:
  - スライドタイトル
  - 主要な発見を説明する3〜5個の簡潔な箇条書き
  - ビジュアルの提案（棒グラフ、折れ線グラフ、円グラフなど）
- シンプルでスライドに適した言語を使用。専門用語や技術的な用語は避ける
```

### **🎨 YAML形式でデザインを制御する高度なプロンプト**

NotebookLMの最大の特徴の一つは、YAML形式でスライドのデザインやスタイルを細かく制御できることです。

#### **4. Blue Monoスタイル（ビジネス向け）**

```yaml
# presentation_design_spec_bold_modern.yaml
# Style: Cobalt & Canvas (Bold Typographic Modernism)

Overall Design Settings:
  Tone: "Artistic, confident, structural, and bold."
  Visual Motif: "Typography as the primary graphic element."
  Color Palette:
    Primary Backgrounds: 
      - "#1A4FA0 (Cobalt Blue) - セクション区切りとインパクトスライド用"
      - "#E8E6E1 (Warm Beige) - コンテンツ重視のスライドとカバー用"
    Text Colors: 
      - "#1A4FA0 (Cobalt Blue) - ベージュ背景上"
      - "#FFFFFF (White) - ブルー背景上"
      - "#000000 (Black) - ベージュ上の本文テキスト用"
```

### **🔧 実践的なワークフロー**

**最も効果的な使い方：**

1. **ソースを準備**：PDF、Googleドキュメント、WebサイトURL、YouTube動画などを登録
2. **プロンプトを選択**：上記から目的に合ったプロンプトを選ぶ
3. **カスタマイズ指示を追加**：聴衆、スタイル、枚数などの具体的な要求を明記
4. **生成と微調整**：結果を確認し、必要に応じて再指示
5. **エクスポート**：PDFでダウンロード（編集が必要な場合はCanva経由でPowerPoint変換）

### **✨ プロのヒント**

- **気に入ったスタイルは保存**：成功したYAMLテンプレートを資産としてストック
- **スピーカーノートを活用**：自動生成される発表者用メモで本番準備
- **Deep Researchと組み合わせ**：調査からスライド作成まで一貫したワークフロー
- **画像の追加**：手書きメモの写真もソースとして利用可能

NotebookLMは単なるスライド生成ツールではなく、思考の整理と視覚化を支援する強力なパートナーです。これらのプロンプトを活用して、資料作成の時間を大幅に短縮しましょう！
