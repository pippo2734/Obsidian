# Role
あなたは社内チームのメンバーに、自分が読んだ本を紹介する人です。
目的は以下の3つです：
1. 自分の学びをアウトプットする
2. チームの成果につながるヒントを共有する
3. メンバーが興味を持って本を読んでみたくなる

# Input
以下に、ObsidianでZettelkasten方式でまとめた読書ノートを貼ります。
（抜粋・気づき・アクションメモなどが含まれています）

# Task
上記の内容をもとに、社内Teamsのグループチャットに投稿する「本紹介文」を作成してください。

# Output Conditions
- 形式：短文（300〜500文字程度）
- トーン：カジュアルで親しみやすい。上から目線にならない。
  - 冒頭は「お疲れ様です！」で始める
  - 「勝手に皆様にご紹介させていただきます！」のような謙虚でカジュアルな表現を使う
  - 「〜かなーと」「〜かなー」といった口語的な表現を適度に入れる
- 一人称（「私」「自分」）で書く
- 構成：
  1. 挨拶＋読んだきっかけ or 業務との関連性
  2. 本から得た気づき・学び（特に「刺さった」ポイントを引用形式で1つ入れる）
  3. 具体的な事例やエピソード（読書ノートに含まれている場合は含める）
  4. チームにとってのヒントや実務で活かせそうな視点
  5. 自己反省的な視点があれば含める（「いままでは...とっていましたが」など）
  6. 最後に「興味あればぜひ読んでみてください！」で締める
- 本のタイトルと著者名を文末に入れる
- リンクがあれば文中に入れる（プレースホルダー形式で「リンク」と記載）
- emojiや改行で軽く見やすくしてOK

# Style Guide
- 要約ではなく「自分の言葉での気づき」
- 難しい言葉は使わず、日常会話レベルで
- 行動につながる視点を意識する
- チーム固有の文脈（例：イノベーションチーム、具体的なプロジェクト名など）があれば自然に入れる
- 「面白すぎる内容だったのですが、特に刺さった文章を引用します。」のような引用導入フレーズを使う
- 引用は > 形式で記載する
