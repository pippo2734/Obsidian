## 評価項目②：成長度（評価制度Ver.2）

### ■ 評価の目的
「できる業務が増えたか」「判断力・対応力が上がったか」を客観的に評価する。  
成長の結果として、ルームリーダーへの昇格・社員登用の道が拓かれる。

---

### ■ 評価スコア（1〜5点）

| 点数  | 評価基準                                                | 想定される行動・状態                                             |
| --- | --------------------------------------------------- | ------------------------------------------------------ |
| 5点  | 上司のサポートなく業務を幅広く自律的に遂行できる。<br>他者の補助・業務改善・指導的役割も行っている | - 1ルームの定例業務を自己完結<br>- 映写資料を主導で更新<br>- 新人フォロー／Teamsでの共有 |
| 4点  | 複数領域の業務を安定して自走できる。<br>他者に任せられる状態にある                 | - 映写資料／紹介入力／アリー／トラブル報告などがミスなく遂行できている                   |
| 3点  | 基本業務を自走で対応できている（習熟済み）<br>ただし新領域への挑戦は少ない             | - 指示後であれば問題なく処理できる<br>- 誤入力や相談の頻度が減ってきている              |
| 2点  | 一部業務は自走可だが、判断に迷いが多くミスもある<br>業務の幅が限定的                | - 業務によっては都度フォローが必要<br>- 基本操作でのミスが散見される                 |
| 1点  | 同じミス・不理解が継続し、改善の兆しが見られない                            | - 指摘内容が継続／成長ログに乏しい                                     |

---

### ■ 評価対象の業務範囲（できることチェックの土台）

| 分類   | 内容                                |
| ---- | --------------------------------- |
| 接客系  | 各種手続き・トークの柔軟性・Safieでの接客精度         |
| 事務系  | 映写資料／紹介入力／アリー基準入力／Teams報告／ミス対応フロー |
| 上位業務 | 改善提案／手順共有／他者フォロー／Backlog上の業務起票・管理 |

---

### ■ 判断材料（上司が確認する情報）

- Backlogの課題内容（本人起票・更新内容）
- Safie音声による判断力の成長記録
- 映写資料や手順資料の編集履歴（Canva・Slack投稿など）
- Teams上の他者との連携（OJT・声かけ・質問対応など）

---

### ■ 備考（成長とリーダー昇格の関係）

- 評価「5点」が継続されると、**自然と“任せられる人材”として認識される**
- 成長度の継続加点は、「昇格候補者選出の根拠」となる（昇格条件ではない）
- 評価制度は、本人の努力と成果を“昇格につなげる回路”として設計されている
