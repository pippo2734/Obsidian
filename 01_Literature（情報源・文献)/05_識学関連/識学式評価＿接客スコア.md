# RURA接客スコア評価制度【最終版：2025年5月更新】

## ■ 評価目的
RURAオペレーターの接客業務に対し、「件数」と「対応時間」双方から業務成果を可視化し、  
定量的かつ役割に応じた絶対評価を行うことで、努力が報われる仕組みを実現する。

---

## ■ 接客スコアの算出式
- 接客件数：1件＝1点
- 対応時間：5分＝1点（負荷も加味）

---

## ■ 評価点の基準（Ver.4｜2025年5月改訂）

### 【フル稼働スタッフ（RURA比率 100%）】

| 評価点 | スコア     |
| --- | ------- |
| 5点  | 500以上   |
| 4点  | 300〜499 |
| 3点  | 180〜299 |
| 2点  | 120〜179 |
| 1点  | 〜119    |

---

### 【兼務スタッフ（RURA比率 40%）】

| 評価点 | スコア     |
| --- | ------- |
| 5点  | 200以上   |
| 4点  | 120〜199 |
| 3点  | 72〜119  |
| 2点  | 48〜71   |
| 1点  | 〜47     |

※RURA稼働比率に応じてスコア基準をスライドさせて公平に評価

---

## ■ 評価補足ルール

- 評価点は原則、接客スコアに基づくが、**欠勤日数・全体貢献・自発性の有無なども補正判断材料**とする  
- 月ごとの繁忙状況（例：5月の混雑期）は基準調整に反映する場合あり  
- スコアは努力の見える化として面談・昇格・フィードバック時に活用

---

## ■ 評価デモ：架空の3名による評価例

### 【評価例1】山田（フル稼働）

- 接客件数：112件  
- 接客時間：435分  
- 計算式：112 + (435 ÷ 5) = 199  
- 評価点：**3点**（基準達成、標準レベル）

---

### 【評価例2】佐藤（兼務スタッフ）

- 接客件数：88件  
- 接客時間：340分  
- 計算式：88 + (340 ÷ 5) = 156  
- 評価点：**4点**（兼務でも非常に高い成果）

---

### 【評価例3】田中（兼務スタッフ）

- 接客件数：4件  
- 接客時間：21分  
- 計算式：4 + (21 ÷ 5) = 8.2  
- 評価点：**1点**（明確な成果不足）

---

## ■ 備考

- 評価結果はBacklog課題テンプレにて毎月記録
- Teamsでの業務連携・映写資料改善・トーク提案等は別軸「成長度」で評価
- 月次でChatGPT＋CSV連携により自動計算・配信を実施中
